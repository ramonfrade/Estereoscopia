
desejo construir um sistema que detecta objetos usando duas câmeras e estima a distância do objeto, usando o conceito de estereoscopia.
deve ser utilizada a linguagem de programação python e a biblioteca opencv com uso de duas câmeras logitech.
considere que este projeto deve ser desenvolvido para ser executado em sistemas linux.

o lsusb detectou as câmeras como:
